# 파이썬 프로그래밍 - 숫자야구 과제


## 과제 목적
- 클래스의 이해
  파일 입출력의 이해
  예외 처리의 이해


## 과제 내용
- 숫자야구 게임을 구현한 후에 파일 입출력을 통해서
  랭킹 데이터를 관리 및 출력하는 프로그램을 작성한다


## 개발환경
- 언어: Python
- Python 버전: 3.12.2
- 운영체제: Windows 10
- 에디터: Visual Studio Code


## 느낀점 및 개선사항
- 예외 처리를 통해 사용자의 입력을 제한하는 것이 중요하다는 것을 깨달았고
  첫 코딩 과제를 해보니까 이 정도의 코드를 짜는 데에도 많은 시간을 들여서
  더욱더 많은 연습이 필요하다는 것을 깨달았다
  그리고 랭킹 데이터와 질의 데이터 부분을 더욱 효율적으로 관리하기 위해
  많은 알고리즘을 알아보고 연습해야겠다고 느꼈다
