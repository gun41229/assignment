# 파이썬 프로그래밍 - 지뢰찾기 게임 과제


## 과제 목적
- 클래스의 이해
  난수 생성과 시드의 이해
  파일 입출력의 이해
  재귀함수의 이해
  예외 처리의 이해


## 과제 내용
- 지뢰찾기 게임을 구현한 후에 파일 입출력을 통해서
  랭킹 데이터를 관리 및 출력하는 프로그램을 작성한다


## 개발환경
- 언어: Python
- Python 버전: 3.12.2
- 운영체제: Windows 11
- 에디터: Visual Studio Code


## 느낀점 및 개선사항
- 이전 과제와 마찬가지로 랭킹 데이터를 처리하기 위해 같은 알고리즘을 사용했는데
  다른 효율적인 알고리즘을 알아봐야겠다고 생각했고
  이번에는 게임 재시작과 재귀 함수를 이용하여 연속적인 칸 열기라는 변수가 있었기 때문에
  저번보다 더욱 많은 시간을 들였다. 이를 위해서 꾸준한 연습이 필요하다는 것을 깨달았고
  전에 작성한 코드를 읽어보면서 자신이 어떤 것을 위해 작성한 것인지 쉽고 빠르게 이해하기 위해
  가독성 있는 코드와 주석의 필요성을 느꼈다
