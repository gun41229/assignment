# C 프로그래밍 - 주소록 관리 프로그램


## 과제 목적
- 구조체의 이해
- stdlib 헤더 파일과 동적할당의 이해
- string 헤더 파일과 문자열의 이해


## 과제 내용
- 사용자의 입력을 통해 주소록, 이름, 전화번호를 관리하고
  다양한 기능을 지원하는 프로그램을 작성한다


## 개발환경
- 언어: C
- IDE: Visual Studio 2022
- Visual Studio 버전: 17.14.0
- 플랫폼 도구 집합: Visual Studio 2022 (v143)
- 빌드 구성: Debug / x64
- 운영체제: Windows 11



## 느낀점 및 개선사항
- 정렬을 하는 알고리즘을 검색하니 시간 복잡도 개념이 나왔다.
시간 복잡도에 대해 조사를 하니 내가 사용한 퀵 정렬이 좋은 정렬이 아니라는 것을 알았고
시간 복잡도를 신경 쓰면서 더 나은 정렬방법을 조사해야겠다.
그리고 현재 배열의 최대 크기가 작지만 커졌을 경우에서 메모리와, 수행 시간 관리를 위해
코드를 검토하고 개선해야겠다고 느꼈다.
