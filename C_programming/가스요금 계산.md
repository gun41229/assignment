# C 프로그래밍 - 도시가스요금 계산 프로그램


## 과제 목적
- 표준 입출력의 이해
- 조건 문의 이해


## 과제 내용
- 도시가스 사용량을 입력받아 요금을 계산한다


## 개발환경
- 언어: C
- IDE: Visual Studio 2022
- Visual Studio 버전: 17.14.0
- 플랫폼 도구 집합: Visual Studio 2022 (v143)
- 빌드 구성: Debug / x64
- 운영체제: Windows 11



## 느낀점 및 개선사항
- C언어를 향한 첫걸음으로, 자신이 거주하는 지역의 도시가스 요금을
  계산하는 프로그램을 만들었다. 쉬운 편이었지만 파이썬과 다른 방식이라
  적응하는데 시간이 조금 걸렸다.
