# 객체지향 프로그래밍 -  ATM 프로그램 작성 Part 1


## 과제 목적
- 동적할당의 이해
  객체지향 프로그래밍의 이해


## 과제 내용
- 교수님이 제시하신 헤더 파일 (Account.h, ATMmachine.h)를 기반으로 하여
  구현부 (Account.cpp, ATMmachine.cpp)를 작성하는 과제이다.
  추가 기능을 구현하면 가산점을 받을 수 있다.
  
  필수기능으로는 계좌 개설 기능, 조회 기능을 구현하는 것 이며,
  계좌 해지, 입금, 출금 기능을 각각 구현하면 가산점이 주어진다.


## 개발환경
- 언어: C++
- 표준: C++14
- IDE: Visual Studio 2022
- Visual Studio 버전: 17.14.0
- 플랫폼 도구 집합: Visual Studio 2022 (v143)
- 빌드 구성: Debug / x64
- 운영체제: Windows 11

## 느낀점 및 개선사항
- 교수님이 인터페이스를 제공하고 그것을 구현하는 형식의 과제는 처음이었다.
인터페이스가 주어지니 그것을 어떻게 구현해야 할지 스스로 설계해야 했고
헤더에 정의된 함수가 어떤 기능을 하는지 분석해야 했다. 그리고 함수 단위로
정상적인 동작을 하는지 디버깅을 함으로써 나 자신을 성장시킨 계기가 되었다.

- 계좌 해지 기능에서 문제가 있다고 했는데 계좌번호 중복방지 기능을 넣지 못해
발생한 것으로 추측된다.
