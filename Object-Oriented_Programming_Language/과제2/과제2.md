# 객체지향 프로그래밍 -  ATM 프로그램 작성 Part 2


## 과제 목적
- 동적할당의 이해
  객체지향 프로그래밍의 이해
  정적 멤버함수의 이해


## 과제 내용
- 교수님이 제시하신 헤더 파일 (Account.h, ATMmachine.h)를 기반으로 하여
  구현부 (Account.cpp, ATMmachine.cpp)를 작성하는 과제이다.
  추가 기능을 구현하면 가산점을 받을 수 있다.

  필수기능은 1차 기능의 기본기능, 추가 기능을 구현하는 것 이며,
  이체 기능, 비밀번호 변경 기능, 고객 관리(통계) 기능을 각각 구현하면 가산점이 주어진다.


## 개발환경
- 언어: C++
- 표준: C++14
- IDE: Visual Studio 2022
- Visual Studio 버전: 17.14.0
- 플랫폼 도구 집합: Visual Studio 2022 (v143)
- 빌드 구성: Debug / x64
- 운영체제: Windows 11


## 느낀점 및 개선사항
- 이전에 작성한 코드를 다시 보고 이해하려 하니 이해가 되지 않는 부분이 많이 있었다.
이러한 문제를 해결하기 위해 주석과 이해하기 쉬운 코드로 작성하는 것이 많이 중요하다는 것을 느꼈다.
그리고, 새로운 기능을 추가하면서 기존 구조의 한계를 인식할 수 있었고,
기존 프로그램의 문제점인 해지 기능을 개선하면서 디버깅 능력이 향상되었다.
