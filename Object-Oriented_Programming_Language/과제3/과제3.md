# 객체지향 프로그래밍 -  ATM 프로그램 작성 Part 2


## 과제 목적
- 동적할당의 이해
- 객체지향 프로그래밍의 이해
- 정적 멤버함수의 이해
- 상속의 이해


## 과제 내용
- 교수님이 제시하신 헤더 파일 (TicketBox.h, Screen.h)를 기반으로 하여
  구현부 (TicketBox.cpp, Screen.cpp)를 작성하는 과제이다.
- 추가 기능을 구현하면 가산점을 받을 수 있다.

- 필수 기능으로는 현재 영화의 정보 보기, 좌석 예약 현황 보기 기능이며,
  좌석 예약 기능, 티켓 결제 기능, 개발자 정의 기능, 통계 기능을 구현하면 가산점이 주어진다.
- 개발자 정의 기능은 본인이 기획하여 구현해야 하며, 적절성, 기능을 소개하는 문서의 완성도, 코드 품질이 평가항목이다.


## 개발환경
- 언어: C++
- 표준: C++14
- IDE: Visual Studio 2022
- Visual Studio 버전: 17.14.0
- 플랫폼 도구 집합: Visual Studio 2022 (v143)
- 빌드 구성: Debug / x64
- 운영체제: Windows 11


## 느낀점 및 개선사항
- 이제 코드만을 작성하는 게 아니라 직접 기능을 기획하고 코드를 작성하는 부분이 추가되었다.
  처음으로 기능을 스스로 기획하며 어떤 기능이 유의미한지 판단했고,
  사용자의 입장에서 어떤 기능이 필요한지 기능의 우선순위 결정의 중요성을 파악하는 계기가 되었다.
  그리고 작은 기능 하나에도 많은 고려 사항이 필요하다는 깨달음을 얻었다.
